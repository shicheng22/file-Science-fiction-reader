# 档案终端 · Archive Terminal

一个单文件运行的科幻风档案管理终端，打开 HTML 即可使用。可以用来整理档案、设计权限与剧情触发，也很适合做互动叙事和演出。

## 特性

- **六个页面**：档案、终端、邮箱、密钥访问、档案库、设置
- **权限系统**：游客、C、B、A、S、管理员六级，密钥前缀区分身份，可自定义角色
- **分级与分类**：内置绝密、A、B、C、公开、私密分级，分类与标签可自行增删
- **触发器系统**：30 多种动作，包括显示文本、可对话的对话框、修改正文、增删图片、损坏与修复档案、发送邮件、切换权限、迁移档案等
- **全局终端**：输入触发词执行事件，与档案内触发器相互独立
- **邮箱**：支持定时到达、条件自动回复、系统通知与提示音
- **稳定率与终端状态**：顶栏实时显示，异常时会变色闪烁
- **多档案库**：可新建档案库并在库之间迁移档案
- **导入导出**：支持 Markdown、TXT、HTML、JSON，支持批量导入文档
- **体验细节**：打字机阅读效果、解密进度条、草稿自动保存、深浅色模式、自定义主题色、音效开关
- **移动端优先**：深空科幻界面，适配手机竖屏

## 使用

直接用浏览器打开 HTML 文件即可，无需安装依赖，也不需要服务器。数据保存在浏览器本地存储中。
